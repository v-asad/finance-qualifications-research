# Glossary

> Acronyms and terms used across the research docs. **As of:** 22 Oct 2026.

## CFA Program

| Term | Meaning |
|---|---|
| **CFA Institute** | Global not-for-profit (Charlottesville, VA) that awards the CFA charter, CIPM and certificates |
| **CFA® charterholder** | Person who has passed all three levels, met the experience and membership requirements, and holds the charter. Never "a CFA" |
| **Level I / II / III** | The three sequential CFA exams |
| **LM** | Learning Module: the curriculum unit (formerly "reading") |
| **LOS / LO** | Learning Outcome Statement: testable objective within an LM |
| **Topic weight** | Official % range of exam points per topic |
| **Item set / vignette** | Case text followed by a set of questions (L2: 4 MCQs; L3: item sets and essay sets) |
| **Constructed response (CR) / essay** | Typed answers graded by charterholders at a grading event (L3 only) |
| **Pathway** | L3 specialisation: Portfolio Management, Private Markets or Private Wealth (since Feb 2025) |
| **PSM** | Practical Skills Module: required, ungraded applied module (≥1 per level) |
| **MPS** | Minimum Passing Score: criterion-referenced cut score, set by the Board of Governors via modified Angoff and equating; not published |
| **Scale score** | Reported score since Feb 2025 (L1 1000–1900, pass 1600; L2 2000–2900, pass 2600; L3 3000–3900, pass 3600) |
| **Ethics adjustment** | Reported practice of using ethics performance to decide borderline candidates (secondary sources only) |
| **Code and Standards** | Code of Ethics (6 components) and Standards of Professional Conduct I(A)–VII(B), 2024 edition |
| **PCS** | Professional Conduct Statement, filed annually by members and candidates |
| **GIPS®** | Global Investment Performance Standards |
| **CIPM®** | Certificate in Investment Performance Measurement |
| **CBOK** | Candidate Body of Knowledge |
| **Learning Ecosystem** | CFA Institute's study platform (curriculum, practice questions, mocks) |
| **Prometric** | Test-centre vendor for CFA exams |
| **Prep Provider Program** | CFA Institute's listing programme for third-party prep providers |

| Term | Meaning |
|---|---|
| **ACCA** | Association of Chartered Certified Accountants (UK, global) |
| **AK / AS / SP** | Applied Knowledge / Applied Skills / Strategic Professional levels (current structure) |
| **BT, MA, FA** | Business & Technology, Management Accounting, Financial Accounting |
| **LW, PM, TX, FR, AA, FM** | Corporate & Business Law, Performance Management, Taxation, Financial Reporting, Audit & Assurance, Financial Management |
| **SBL, SBR** | Strategic Business Leader, Strategic Business Reporting (Essentials) |
| **AFM, APM, ATX, AAA** | Advanced Financial Management, Advanced Performance Management, Advanced Taxation, Advanced Audit & Assurance (Options) |
| **EPSM** | Ethics and Professional Skills Module |
| **PER / PO** | Practical Experience Requirement (36 months) / Performance Objectives |
| **CBE** | Computer-Based Exam (on-demand or session) |
| **OT / OT case / MTQ / CR** | Objective Test / OT case (scenario + 5 OTs) / Multi-Task Question / Constructed Response |
| **Variant** | Country-specific version of LW, TX, ATX (e.g. UK, PKN, MYS) |
| **FIA** | Foundations in Accountancy (entry-level awards) |
| **ALP** | Approved Learning Partner (Silver/Gold/Platinum) |
| **EEM** | Essential Employability Module (2027 redesign) |

## Psychometrics and product

| Term | Meaning |
|---|---|
| **Angoff method** | Standard-setting method where experts estimate how a minimally competent candidate would perform on each item |
| **Equating** | Statistical adjustment so different exam forms have equivalent pass standards |
| **IRT** | Item Response Theory: model for item difficulty/discrimination and learner ability |
| **Blueprint** | Mapping of exam content to topic weights used to assemble mocks |
| **Crosswalk** | Mapping between learning outcomes of two syllabus versions |
